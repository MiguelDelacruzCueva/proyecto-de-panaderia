# 🥖 Capi-Tan: Panadería Online 🍞

**Bienvenido a Capi-Tan**, un proyecto desarrollado en **Laravel 11** como parte del curso de Desarrollo Web Full-Stack en la universidad. Este sistema web está enfocado en la gestión de una panadería, brindando una plataforma interactiva para la administración de productos, usuarios y compras.

## 🚀 Tecnologías utilizadas
- 🛠️ **Back-End:** PHP (Laravel 11)
- 🎨 **Front-End:** HTML, CSS, JavaScript (Bootstrap)
- 🗄️ **Base de datos:** MySQL (SGBD)
- 🔒 **Autenticación:** Sistema de login con diferentes roles (Administrador, usuario nuevo y usuario registrado)

## 🔥 Características
✔️ **Interfaz amigable** con un diseño moderno y accesible.  
✔️ **Sistema de autenticación** para garantizar el acceso seguro.  
✔️ **Gestión de productos** con capacidad de agregar, editar y eliminar elementos del catálogo.  
✔️ **Administración de usuarios** según su tipo de cuenta.  
✔️ **Integración con MySQL** para el almacenamiento de datos.  

## 🚧 Mejoras y aspectos por pulir
⚠️ **Seguridad:** Se requiere una mejor personalización del sistema tras el login.  
⚠️ **Sistema de compras:** Próxima integración para permitir la adquisición de productos desde la web.  
⚠️ **Optimización del rendimiento:** Potencial para mejorar la eficiencia de la plataforma.  

## 💡 Futuro del proyecto
Este sistema tiene **un gran potencial** si se mejora y optimiza, por lo que estoy comprometido en seguir evolucionándolo para ofrecer una experiencia más robusta y profesional. 🚀
